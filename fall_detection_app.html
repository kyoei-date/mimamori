Sensitivity

感度設定

感度・キャンセル時間などはコード内の DEFAULT_SETTINGS で全端末共通に管理されています。下は現在の設定値の確認用で、この画面からは変更できません。変更したい場合は管理者にファイルの書き換えを依頼してください。
どの感度でも、衝撃を検知した後に「体が動いていないか」を確認してから警告します（衝撃だけでは反応しません）。感度が低いほど、衝撃の判定基準と静止の判定基準の両方が厳しくなります。
※ iPhone（iOS）は仕様上バイブレーションに対応していないため、音のみで通知されます。Androidではバイブも鳴ります。

Worker Links

作業者用リンクの発行

HTMLファイル内の WORKER_LIST に作業者名を登録すると、ここに一人ずつ専用のURLが表示されます。そのURLをLINEなどで本人に送るだけで、作業者側は名前入力が不要になります（リンクを開くと自動でその名前が設定され、入力欄はロックされます）。
まだ WORKER_LIST に名前が登録されていません。ファイル内の WORKER_LIST = [] に名前を追加してください（例: ['田中太郎', '佐々木']）。
Notify

通知先メール設定（EmailJS）

Service ID・Template ID・Public Key・通知先メールアドレスは、コード内の DEFAULT_SETTINGS で全端末共通に管理されており、この画面では確認のみで編集できません。内容を変更する場合は、HTMLファイル内の DEFAULT_SETTINGS を書き換えて配布し直してください（配布し直せば、次回起動時に全端末へ自動で反映されます）。
EmailJSの設定手順（DEFAULT_SETTINGSへの反映方法）
1. https://www.emailjs.com/ で無料アカウントを作成
2. 「Email Services」→ Gmail等を接続 → Service ID をコピー
3. 「Email Templates」→ 新規テンプレート作成。本文に以下の変数を含める：
{{worker_name}} {{message}} {{time}} {{location}}
→ Template ID をコピー
4. 「Account」→ 「API Keys」→ Public Key をコピー
5. 上の3つと通知先メールアドレスを、HTMLファイル内の DEFAULT_SETTINGS に書き込んで保存
6. ファイルを配布し直す（GitHub Pages等のURLを更新）
7. 各端末で開き直し、「テスト通知」ボタンで実際に届くか確認してください

※ 既にテンプレートを作成済みの場合は、EmailJSの管理画面でテンプレート本文に 作業者: {{worker_name}} を追記し、保存し直してください。

※ 複数人に通知するには、テンプレート編集画面の右側にある「To Email」欄を、固定のメールアドレスではなく {{to_email}} という変数に変更して保存してください。これをしないと、登録した2人目以降に届きません。
